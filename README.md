# BogieVision Inspection Console

A browser-based railway bogie and undercarriage foreign-object inspection console built with React and Vite. Prepared for integration with a separate FastAPI backend running Vision Transformer (ViT) and DINO feature memory bank anomaly detection.

Requires Node.js 18+.

---

## Requirements

- **Node.js 18+** — [nodejs.org](https://nodejs.org/)
- A modern browser (Chrome, Firefox, Safari, Edge)
- For live camera: serve over HTTPS or `localhost` (browser security requirement)
- Optional: Running FastAPI AI Backend (`POST /api/inspect`)

---

## Getting started

```bash
# 1. Install dependencies
npm install

# 2. Configure environment (optional, defaults to http://localhost:8000)
cp .env.example .env

# 3. Start the development server (http://localhost:5173)
npm run dev

# 4. Production build (outputs to dist/)
npm run build

# 5. Preview the production build locally
npm run preview
```

## Backend Integration API Contract

The frontend connects to the Python backend via `src/services/inspectionApi.js`.

### Endpoint
`POST /api/inspect`
**Content-Type:** `multipart/form-data`

### Form Fields
| Field | Type | Description |
|---|---|---|
| `image` | Binary (Blob/File) | Undercarriage inspection frame (JPEG, PNG, WebP) |
| `train_number` | string | Train identifier (e.g. `WAP-7 30723`) |
| `coach_bogie` | string | Coach or bogie position (e.g. `B2 · Bogie 01`) |
| `inspection_location` | string | Track / depot location (e.g. `Pit line 3, New Delhi`) |
| `officer_id` | string | Inspector badge or staff ID |

### Expected JSON Response
```json
{
  "status": "success",
  "verdict": "DEFECT DETECTED",
  "defect_percentage": 2.35,
  "regions_count": 2,
  "peak_score": 0.31,
  "regions": [
    {
      "id": "region-1",
      "x": 420,
      "y": 180,
      "width": 65,
      "height": 42,
      "anomaly_score": 0.31,
      "description": "Visual deviation detected by ViT feature memory bank"
    }
  ],
  "annotated_image": "base64-image-data-or-url"
}
```

## Features

- **Real AI Backend Ready:** Clean API service layer with request timeouts, abort controller cancellation, error normalization, and response validation.
- **Image sources:** Upload (PNG, JPEG, WebP), live camera (capture frame), reference demo frame (for UI testing without fake detection).
- **Inspection record:** Train number and location required; explicit Save enforced before scanning. Editing any field invalidates the record.
- **Scan gates:** Start detection requires (1) Still image present, (2) Inspection record saved, (3) Operator area clear confirmed.
- **Image viewer:** Displays original frame, backend-generated annotated image, and dynamic bounding box overlays scaled to image natural dimensions.
- **Diagnostic views:** Offscreen canvas-based Grayscale, Blur, Threshold, and Sobel edge-map views.
- **Quality gate:** Minimum resolution 640 × 360 check.
- **Release / Maintenance decisions:** Recorded immediately as an operator action, locked after first decision.
- **JSON report export:** Machine-readable inspection report containing train details, image metadata, real AI verdict, anomaly coordinates/scores, and operator decision.
- **Activity log:** Chronological audit trail of session events.
- **Theme:** Light/dark mode with OS preference detection.
- **Glassmorphic UI:** Apple-inspired design tokens with accessible focus management.
